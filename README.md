# BadUSB
＜説明＞
このBad USBは、特定のフォルダをD:などの外部デバイスにCAPしてマウントするプログラムです。
一応初期設定としてDesktopフォルダをD;にマウントするように設計してますが、目的に応じて変更してください。
ただ、グループポリシーエディタでCmdがブロックされている場合を考慮し、Cmdは避けています（Cmd版は後日出します）

＜利用方法＞
一応.txtファイルにしているので、このままFlipper Zeroなどの外部デバイスに登録して実行してください

なお、このプログラムによって生じた一切の損害に作成者は責任を負いかねます。また、一切の悪用を禁じます。
制作・著作　Asfalt94
